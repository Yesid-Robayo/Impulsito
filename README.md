# Impulsito

App Android gratuita para que la persona dueña de un emprendimiento sepa qué tiene, cuánto gana por cada producto y cuánto ganó este
mes. Funciona sin internet, no tiene servidores y respalda los datos en la nube que esa persona elija.

**Estado:** en construcción. Todavía no hay una versión para descargar.

## Descarga

Desde la versión `1.0.0`, el APK se publica en los Releases de este repositorio, con su suma SHA-256. No hay tiendas de aplicaciones.
Antes de instalar, compara la huella del certificado con la que publica la página oficial.

## Reportes

- **No se aceptan pull requests.** El código solo lo cambia quien mantiene la app.
- **Los issues son para reportar** fallos, dudas y propuestas. No adjuntes copias, bases, CSV ni capturas con datos reales de un negocio
  o de sus clientes.
- **Un fallo de seguridad no va en un issue:** usa el reporte privado de vulnerabilidades del repositorio.
- No hay compromiso de tiempo de respuesta.

## Importante

Impulsito no reemplaza la contabilidad oficial ni emite facturas fiscales. Sus comprobantes son internos. Cada negocio debe confirmar con
quien lo asesora qué le exigen las normas de su lugar.
