Cifrar las copias es opcional y viene apagado. Con el cifrado, nadie puede abrir las copias sin el código, aunque entre a la cuenta de la nube o a la carpeta de copias.

## Activar

En **Cifrado de copias**, **Activar cifrado** crea un código de recuperación de 28 caracteres. Por seguridad, no se puede copiar ni capturar en pantalla: se anota a mano o se guarda con **Guardar kit de recuperación**, fuera de este teléfono y fuera de la misma cuenta de la nube. Después se escribe una vez, para confirmar que quedó bien guardado. Antes de activarse, {app} prueba que una copia cifrada se pueda abrir.

## Lo que conviene saber

- **Mientras el teléfono funcione, el código no hace falta.** **Ver mi código** lo muestra otra vez.
- **Sin el teléfono, el código es la única forma de abrir las copias.** Si se pierden el teléfono y todas las copias del código, los datos no se pueden recuperar, y nadie puede ayudar.
- {app} pide escribirlo de vez en cuando, en **Comprobar el código**, para saber que sigue a mano. Un código mal escrito nunca borra ni bloquea nada.
- El cifrado protege las copias, no los datos de este teléfono. Las copias anteriores sin cifrar salen con la retención normal.

## Cambiar o apagar

- **Cambiar el código** crea uno nuevo. Las copias con el código anterior se conservan hasta comprobar una con el nuevo.
- **Desactivar cifrado**: la siguiente copia sale sin cifrar, y las cifradas se conservan hasta comprobarla. Esas copias siguen necesitando su código. Volver a activar crea un código nuevo.
