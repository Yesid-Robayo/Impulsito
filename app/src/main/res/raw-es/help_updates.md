{app} se instala con su archivo de instalación firmado, un archivo .apk.

## Instalar

- Instalar siempre con un archivo firmado por quien publica {app}. Android puede pedir permiso para instalar desde esa app.
- Para pasar los datos a otro teléfono, ver [Restaurar en un teléfono nuevo](help_restore).

## Actualizar

- Una versión nueva se instala encima de la anterior, con un archivo con la misma firma, y los datos se conservan.
- Antes de actualizar, conviene mirar que la copia esté al día.
- Si una actualización cambia la forma en que se guardan los datos, {app} hace antes una copia.

## Lo que nunca se debe hacer

- **Nunca desinstalar {app} si una actualización no se instala.** Si el teléfono habla de una firma distinta o de desarrolladores sin verificar, conviene pedir ayuda: desinstalar borra los datos de este teléfono.
- Nunca instalar un archivo de origen dudoso.
