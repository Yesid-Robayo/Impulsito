With a barcode on each product, selling, buying and counting are done by pointing the camera, without searching by name. If a product has no code, {app} creates one and prints it on a label.

## Give a product a code

- While editing the product, under **More details**, **Barcode**: type it or read it with the camera, using the field's button.
- **Generate code** creates a unique code of its own for a saved product that has none.
- A code already used by another product is not saved: the field says which one has it.
- A conversion, such as a box, can have its own code: when it is read in a sale, the line comes in that unit.

## Scan

The scanner opens with the scan button in **Sell**, in a purchase, in a count, in **Products** and in the inventory.

- In a sale, a purchase or a count, reading is continuous: each code read is added and the camera stays open until **Finish** is tapped. **Last** shows the code read.
- A product held still in front of the camera is added only once. To add it again, move it out of the frame and show it again.
- In a count, each read adds one unit. If the product's unit allows decimals, such as weight, or if it has several batches, it is searched for so the quantity can be typed.
- In **Products** and in the inventory, reading a code opens the product.

A code that no product has opens **Code without a product**, with **Create product** or **Assign to a product**. One that belongs to an archived product offers **Reactivate**. In low light, the flashlight helps.

## The camera

Camera permission is asked for only when the scanner opens, with **Allow camera**. The camera is used only to read codes, and only while that screen is open: no image is saved or leaves the phone. Without permission, or if the camera does not open, **Type the code** works just as well.

## Printable labels

In **Business**, **Printable labels**, or in **Products**, ⋮ → **Printable labels**:

1. **Which products**: **Choose**, by **Category**, or **Only price changes** **Since** a date. Each product can have several copies.
2. **Template**: **Name and price**, **Name, price and code** or **Code only**.
3. **Size**: **58 mm** or **80 mm** for a thermal printer paired by Bluetooth, or **PDF sheet**, which with **Create PDF** opens the phone's printing.
4. Print. A preview shows the first label.

If the template has a code and some products have none, **Generate codes** creates them and saves them on each product. If it has a price, products without a price are left out. Without a printer, **Set up printer** chooses one from the paired ones.
