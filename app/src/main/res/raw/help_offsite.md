A backup outside the cloud protects the business if that account is lost. It is in **Local backups**, in **Settings**.

## Export a full backup

**Save to a file** creates a file with all the data, to keep on the phone, a card or a USB drive. It can be used to restore with **Find a file**.

## Automatic second destination

Once a day, if there were changes, {app} makes a backup in a folder on this phone, a card or a USB drive, with or without a cloud connected, and keeps the last 3.

With **Keep this folder up to date**, each cloud backup is also saved there, and without a cloud or without internet one is made a few minutes after each change. It keeps the last 3 and the last one from each of the two previous days.

When choosing **Documents**, or a folder on an SD card, {app} creates a folder with its name inside it, which stays there even if the app is uninstalled. That folder is used to recover the data after reinstalling: never delete it.

## Photos

Photos are not part of the backup. Export them separately, in a ZIP file, with **Export photos**.

## Handle with care

Without encryption, that file contains the whole business, and it must be stored carefully. A local backup does not replace the cloud: if it is kept next to the phone, it can be lost along with it.
