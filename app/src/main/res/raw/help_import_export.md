## Import

**Import data**, in **Business**, brings in products, customers, suppliers or the price index from a CSV or spreadsheet file (.xlsx), in Spanish, English or Portuguese.

1. Choose what to import and the file. The file is read on this phone and is not sent anywhere.
2. **Match columns**: say what each column contains. Known columns are recognized automatically.
3. **Review before importing**: how many rows are ready, how many already exist and which ones have a problem.
4. Import.

The first imported amount locks the currency and its decimals.

## Export

In **Settings**:

- **Export to CSV**: a .zip file with one CSV for each type of data.
- **Export to spreadsheet**: an .xlsx file with one sheet for each type of data.
- **Export a date range**: the sales, purchases, expenses and movements of those dates, with all the products and suppliers.

Exporting does not replace backups: restoring uses a backup, not a CSV.

## Handle with care

An exported file contains the whole business. Store it carefully and never send it by chat or by email. With the lock turned on, exporting asks for the fingerprint or PIN again.
