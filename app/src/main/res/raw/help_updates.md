{app} is installed with its signed installation file, an .apk file.

## Install

- Always install with a file signed by whoever publishes {app}. Android may ask for permission to install from that app.
- To move the data to another phone, see [Restore on a new phone](help_restore).

## Update

- A new version is installed over the previous one, with a file that has the same signature, and the data is kept.
- Before updating, check that the backup is up to date.
- If an update changes the way the data is stored, {app} makes a backup first.

## Knowing when there is a new version

- Once a day, with internet, {app} reads the signed version notice on the project page. It sends no data: that page sees the phone's internet address, as when any page is opened.
- If there is a new version, a notification arrives, only once per version, and **Home** says so until it is installed. Both open **Updates and APK check**, which checks again and offers **Update**. Nothing is downloaded or installed until **Update** is tapped, and Android asks to confirm.
- Without internet, or if the notice fails the signature check, nothing happens: it tries again the next day.
- **Check for updates automatically**, in **Updates and APK check**, turns off the daily check. With **Allow update checks** off, {app} never checks, neither on its own nor with the button.

## What never to do

- **Never uninstall {app} if an update does not install.** If the phone mentions a different signature or unverified developers, ask for help: uninstalling deletes the data on this phone.
- Never install a file from a doubtful source.
