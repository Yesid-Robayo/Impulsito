{app} is installed with its signed installation file, an .apk file.

## Install

- Always install with a file signed by whoever publishes {app}. Android may ask for permission to install from that app.
- To move the data to another phone, see [Restore on a new phone](help_restore).

## Update

- A new version is installed over the previous one, with a file that has the same signature, and the data is kept.
- Before updating, check that the backup is up to date.
- If an update changes the way the data is stored, {app} makes a backup first.

## What never to do

- **Never uninstall {app} if an update does not install.** If the phone mentions a different signature or unverified developers, ask for help: uninstalling deletes the data on this phone.
- Never install a file from a doubtful source.
