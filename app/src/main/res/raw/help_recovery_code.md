Encrypting backups is optional and off by default. With encryption, nobody can open the backups without the code, even if they get into the cloud account or the backup folder.

## Turn on

In **Backup encryption**, **Turn on encryption** creates a 28-character recovery code. For security, it cannot be copied or captured in a screenshot: write it down by hand or save it with **Save recovery kit**, outside this phone and outside that same cloud account. Then enter it once, to confirm it was saved correctly. Before encryption is turned on, {app} tests that an encrypted backup can be opened.

## Good to know

- **As long as the phone works, the code is not needed.** **View my code** shows it again.
- **Without the phone, the code is the only way to open the backups.** If the phone and every copy of the code are lost, the data cannot be recovered, and nobody can help.
- {app} asks to enter it from time to time, in **Check the code**, to make sure it is still at hand. A mistyped code never deletes or locks anything.
- Encryption protects the backups, not the data on this phone. Earlier unencrypted backups are removed with the normal retention.

## Change or turn off

- **Change the code** creates a new one. Backups with the old code are kept until one with the new code is checked.
- **Turn off encryption**: the next backup goes out unencrypted, and the encrypted ones are kept until it is checked. Those backups still need their code. Turning it on again creates a new code.
