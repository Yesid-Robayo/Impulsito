With a backup, the data comes back on another phone, or on the same one after reinstalling.

## On a new phone

1. Install {app} with the same signed installation file.
2. On the welcome screen, tap **Bring data from another phone**.
3. With WebDAV: accept the policy, choose **Service with WebDAV**, enter the same service details and choose the most recent backup.
4. With the phone's cloud: tap **Find a file**, go into that cloud and choose the .slcopy file with the most recent date. If it does not open, try the other two, from newest to oldest.
5. With encryption, enter the recovery code.
6. Check the date: {app} says how far the data goes. Anything recorded after that has to be recorded again.
7. With the phone's cloud, choose where to save again: three new files are created, and the old ones are not touched.

**If no backup appears, do not tap Start from scratch.** The backups are still in the cloud, and they can be found with **Find a file**. With WebDAV, the most recent file can also be downloaded to the phone from the service's website, the one that does not end in .slmeta, and chosen with **Find a file**. If none opens, an exported backup or the one in the second destination will do.

## Reinstall on the same phone

If there was a second destination, the backups are still in its folder. On the welcome screen, **Find my backup on this phone** opens that folder and suggests the most recent backup. When restoring, the folder is connected again, and where to save in the cloud has to be chosen again.

## Change phones

1. On the old phone, open {app} with internet and wait until it says **All saved**. With the phone's cloud, tap **Save to Drive** and check that the file appears in that cloud, with that time.
2. On Wi-Fi, wait until no photo is left without a backup. With the phone's cloud, move the photos with **Export photos**.
3. Stop recording on the old phone: {app} is used on only one phone at a time.
4. Bring the data to the new phone, as above, and compare the products, the month's sales and the profit.
5. Keep {app} on the old phone for a week before removing it.

The manufacturer's transfer tool does not carry the {app} data.

## If it was lost or stolen

That same day, from another device, lock the phone with the system service for locating it, and change the cloud password and, with WebDAV, the service password. Then bring the data to another phone. If the old phone turns up, do not record anything on it.
