Only with **Drive on the phone**. {app} hands each backup to that cloud, but cannot know whether it was uploaded. That is why it has to be checked once a week.

## How to check

1. When {app} asks, open that cloud, preferably from another device or from the web.
2. Find the file that {app} names.
3. Check that it has the time that {app} shows, or a newer one. It is not enough that it exists.
4. Tap **Backup seen in Drive**. That button records what was seen: it does not check anything.

**Never tap Backup seen in Drive without having looked.**

## If it does not appear with that time

Do not tap that button. Open that cloud with internet, check that it is signed in and has space, tap **Save to Drive** and check the time again. If it still has not changed, use **Export backup** today, save the file on a USB drive or an SD card, and switch to **Service with WebDAV**.

## The warnings

- **The backup in Drive needs checking**: 7 days have passed without a check. It can appear next to another warning, because none hides it.
- **Sign in to Drive**: the session on the phone was closed, and backups are stopped. After signing in, **Save to Drive** delivers them again, without creating new files.
- **Review the cloud backup**: there is a newer backup or one from another phone, or one of the three files changed outside {app}. Backups stopped so nothing is overwritten. When in doubt, choose **Decide later** and ask for help.
