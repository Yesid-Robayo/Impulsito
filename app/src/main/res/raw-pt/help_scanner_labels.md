Com um código de barras em cada produto, vender, comprar e contar se faz apontando a câmera, sem buscar pelo nome. Se o produto não tem código, {app} cria um e o imprime em uma etiqueta.

## Dar um código a um produto

- Ao editar o produto, em **Mais detalhes**, **Código de barras**: escrevê-lo ou lê-lo com a câmera, com o botão do campo.
- **Gerar código** cria um código próprio, único, para um produto salvo que não tem nenhum.
- Um código que outro produto já usa não é salvo: o campo diz qual o tem.
- Uma conversão, como uma caixa, pode ter o seu próprio código: ao lê-lo em uma venda, a linha entra nessa unidade.

## Ler códigos

O leitor de códigos se abre com o botão de leitura de **Vender**, de uma compra, de uma contagem, de **Produtos** e do estoque.

- Em uma venda, uma compra ou uma contagem, a leitura é contínua: cada código lido é somado e a câmera continua aberta até tocar em **Concluir**. **Último** mostra o código lido.
- Um produto parado na frente da câmera é somado uma só vez. Para somá-lo de novo, tirá-lo do quadro e mostrá-lo outra vez.
- Em uma contagem, cada leitura soma uma unidade. Se a unidade do produto aceita decimais, como o peso, ou se ele tem vários lotes, o produto é buscado para escrever a quantidade.
- Em **Produtos** e no estoque, ler um código abre o produto.

Um código que nenhum produto tem abre **Código sem produto**, com **Criar produto** ou **Atribuir a um produto**. O de um produto arquivado oferece **Reativar**. Com pouca luz, a lanterna ajuda.

## A câmera

A permissão da câmera é pedida só ao abrir o leitor, com **Permitir câmera**. A câmera é usada só para ler códigos, e só com essa tela aberta: nenhuma imagem é salva nem sai do telefone. Sem permissão, ou se a câmera não abrir, **Escrever o código** funciona do mesmo jeito.

## Etiquetas para impressão

Em **Negócio**, **Etiquetas para impressão**, ou em **Produtos**, ⋮ → **Etiquetas para impressão**:

1. **Quais produtos**: **Escolher**, por **Categoria** ou **Só o que mudou de preço** **Desde** uma data. Cada produto pode ter várias cópias.
2. **Modelo**: **Nome e preço**, **Nome, preço e código** ou **Só código**.
3. **Tamanho**: **58 mm** ou **80 mm** para uma impressora térmica pareada por Bluetooth, ou **Folha PDF**, que com **Criar PDF** abre a impressão do telefone.
4. Imprimir. Uma prévia mostra a primeira etiqueta.

Se o modelo leva código e alguns produtos não têm, **Gerar códigos** os cria e os salva em cada produto. Se leva preço, os produtos sem preço ficam de fora. Sem impressora, **Configurar impressora** a escolhe entre as pareadas.
