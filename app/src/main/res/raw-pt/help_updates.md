{app} é instalado com o arquivo de instalação assinado, um arquivo .apk.

## Instalar

- Instalar sempre com um arquivo assinado por quem publica {app}. O Android pode pedir permissão para instalar a partir desse app.
- Para passar os dados para outro telefone, ver [Restaurar em um telefone novo](help_restore).

## Atualizar

- Uma versão nova é instalada por cima da anterior, com um arquivo com a mesma assinatura, e os dados são mantidos.
- Antes de atualizar, convém conferir se a cópia está em dia.
- Se uma atualização mudar a forma como os dados são guardados, {app} faz uma cópia antes.

## O que nunca se deve fazer

- **Nunca desinstalar {app} se uma atualização não for instalada.** Se o telefone falar de uma assinatura diferente ou de desenvolvedores não verificados, convém pedir ajuda: desinstalar apaga os dados deste telefone.
- Nunca instalar um arquivo de origem duvidosa.
