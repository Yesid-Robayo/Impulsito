{app} é instalado com o arquivo de instalação assinado, um arquivo .apk.

## Instalar

- Instalar sempre com um arquivo assinado por quem publica {app}. O Android pode pedir permissão para instalar a partir desse app.
- Para passar os dados para outro telefone, ver [Restaurar em um telefone novo](help_restore).

## Atualizar

- Uma versão nova é instalada por cima da anterior, com um arquivo com a mesma assinatura, e os dados são mantidos.
- Antes de atualizar, convém conferir se a cópia está em dia.
- Se uma atualização mudar a forma como os dados são guardados, {app} faz uma cópia antes.

## Saber se há uma nova versão

- Uma vez por dia, com internet, o {app} consulta o aviso de versão assinado na página do projeto. Não envia nenhum dado: essa página vê o endereço de internet do telefone, como ao abrir qualquer página.
- Se houver uma nova versão, chega uma notificação, uma só vez por versão, e **Início** avisa até que ela seja instalada. As duas abrem **Atualizações e verificação de APK**, que busca de novo e oferece **Atualizar**. Nada é baixado nem instalado sem tocar em **Atualizar**, e o Android pede para confirmar.
- Sem internet, ou se o aviso não passar na verificação de assinatura, nada acontece: tenta de novo no dia seguinte.
- **Buscar atualizações automaticamente**, em **Atualizações e verificação de APK**, desliga a consulta diária. Com **Permitir buscar atualizações** desligado, o {app} nunca consulta, nem sozinho nem com o botão.

## O que nunca se deve fazer

- **Nunca desinstalar {app} se uma atualização não for instalada.** Se o telefone falar de uma assinatura diferente ou de desenvolvedores não verificados, convém pedir ajuda: desinstalar apaga os dados deste telefone.
- Nunca instalar um arquivo de origem duvidosa.
